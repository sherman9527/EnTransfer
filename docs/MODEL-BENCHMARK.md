# 模型横评报告 (Model Benchmark)

> 硬件：i5-12600KF (6P+4E/16线程) · GTX 1060 6GB (Vulkan) · 32GB RAM
> 引擎：node-llama-cpp v3.20.0 纯 ESM · 测试：40 个用例（9 类）· 日期：2026-09-12
> **关键发现：Qwen3 / MiniCPM5 / MiniCPM3 默认开启 thinking（隐藏推理），速度暴跌 ~50×。
> 必须用 `JinjaTemplateChatWrapper({reasoning:false})` 关闭 `enable_thinking` 后才能公平比较。**

---

## 1. 统一最优配置（所有模型调优结论）

| 参数 | 最优值 | 说明 |
|---|---|---|
| 线程数 | **12** | i5-12600KF 的 6 个 P 核超线程，避开 4 个 E 核；6/16 均更慢 |
| context | **1024** | 与 2048 速度几乎相同，KV cache 更小，默认 1024 |
| temperature | **0.1** | 贪心(0) 与 0.1 质量差异小，0.1 略自然 |
| topK / topP | 20 / 0.9 | 固定 |
| GPU offload | **gpuLayers = "max"** | 全层 offload 到 Vulkan |
| reasoning 模型 | **disableReasoning = true** | Qwen3 / MiniCPM5 / MiniCPM3 必开，否则 0.3–1.4 tok/s |

CPU 调优（`tests/results/_tuning.json`）：线程数 12 全局最优；context 1024≈2048。
CPU 速度仅作参考（离线无 GPU 场景），所有推理以 GPU 为准。

---

## 2. Thinking 模式问题（最重要的技术发现）

| 模型 | thinking 开启 (GPU) | thinking 关闭 (GPU) | 加速比 |
|---|---|---|---|
| Qwen3-1.7B | 1.37 tok/s | **70.12 tok/s** | **51×** |
| Qwen3-4B | ~1.4 tok/s | **35.83 tok/s** | ~26× |

原因：这些模型的 GGUF chat template 含 `enable_thinking` 变量，默认 true 时模型先在
`<think>...</think>` 里生成几百 token 推理，再输出正式译文——译文 token 计数几乎为 0。
修复：`JinjaTemplateChatWrapper({template, reasoning:false, tokenizer})`，等价于
`enable_thinking=false`，模板会预填 `<think>\n\n</think>\n\n` 直接跳过思考段。

> **踩坑**：`getEngineConfig(id)` 原来用短 id（`qwen3-1.7b`）查 `ENGINE_CONFIGS`，
> 但键名带量化后缀（`qwen3-1.7b-q4_k_m`），查不到就回退通用配置，导致
> `disableReasoning` 静默失效。已改为前缀归一化匹配。

## 6. 最终推荐

**主推荐模型：Qwen3-1.7B-Q4_K_M.gguf**
- 质量与翻译专用基准 hy-mt2 持平（4.9/5），但速度更快（70 vs 65 tok/s）。
- 体积 1.22GB、VRAM 1647MB，资源占用低，GTX 1060 6GB 余量充足。
- 最优参数：`disableReasoning=true` · context=1024 · threads=12 · temp=0.1 · gpuLayers=max。
- **必须关闭 thinking**，否则从 70 tok/s 暴跌到 1.4 tok/s。

**备选：**
- **hy-mt2-1.8b**：翻译领域专用、已在全书 50 页验证过的稳妥之选；综合分 4.52 紧随其后。
- **qwen3-4b**：若追求最高译文质量（5.0）且可接受 36 tok/s / 2.38GB，作质量天花板备选。

**淘汰**：qwen2.5-1.5b（速度最快但译文有未译词与幻觉）、minicpm5-1b（术语崩塌）、
minicpm5-2b / minicpm3-4b（质量尚可但速度/显存不经济）、qwen2.5-3b（体积大无速度优势）。

> 原默认模型 Hy-MT2 在质量上未被明显超越（qwen3-1.7b 质量持平、速度略优）。
> 依据综合公式与"高质+高速"双优，**默认模型切换为 Qwen3-1.7B（关闭 thinking）**。
