📖 使用说明

日常使用操作指南

1

确保模型已就绪

启动App，查看「模型管理」页面，模型状态应为「已就绪」。如未就绪，请先下载或手动放置模型。

2

添加PDF

点击「添加PDF」按钮选择文件，或直接将英文文字版PDF拖入窗口。支持批量添加。

3

自动排队翻译

任务自动加入队列，按顺序翻译。可在「任务队列」页面查看进度。

4

暂停/恢复/取消

翻译过程中可随时暂停、恢复或取消任务。checkpoint机制确保崩溃后可断点续译。

5

查看输出

翻译完成后，点击「打开文件夹」查看输出的中文PDF。输出文件与源文件同目录。

🔧 从源码编译

开发者指南 — 从源码构建自己的版本

环境要求

  • Node.js ≥ 18
  • Python ≥ 3.8（用于字体子集化，需 pip install fonttools）
  • Git
  • Windows 10/11（系统自带微软雅黑字体）

编译步骤

# 克隆仓库
git clone https://github.com/sherman9527/EnTransfer.git
cd EnTransfer

# 安装依赖
npm install

# 生成子集字体（首次编译需要，从系统微软雅黑提取）
python scripts/subset-font.py

# 开发模式运行
npm run dev

# 打包EXE
npm run build
npm run dist
# 产物在 release/ 目录下

⚠️ 注意事项

使用前请了解以下限制

仅支持文字版PDF — 不支持扫描件/图片PDF（无OCR功能）。如果PDF是图片扫描件，请先使用OCR工具转换为文字版。
仅支持英文→中文 — 当前模型针对英中翻译优化，不支持其他语言对。
表格/公式/图片保留原文 — 这些内容不翻译，原样嵌入输出PDF。正文和标题会翻译。
首次运行需下载模型 — 模型约1.2GB，建议在网络良好时下载。也可手动下载后放置到指定目录。
GPU加速需要Vulkan驱动 — NVIDIA/AMD/Intel显卡需安装最新显卡驱动以支持Vulkan。无GPU时自动回退CPU模式。
