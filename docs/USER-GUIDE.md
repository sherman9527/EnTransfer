# EnTransfer 使用文档

> 英文文字版PDF → 中文PDF 离线翻译工具

## 简介

EnTransfer 是一款 Windows 桌面应用，可将英文文字版PDF高质量翻译为中文PDF。完全离线运行，**自动使用 GPU（Vulkan）加速，无 GPU 时回退 CPU**，所有处理均在本机完成。

**核心特性：**
- 翻译质量优先：采用横评综合最优的 **Qwen3-1.7B Q4_K_M** 模型（质量 4.9/5，已关闭 thinking 推理以提速）
- **GPU 加速**：自动检测 Vulkan GPU（NVIDIA/AMD/Intel），翻译速度提升约 8 倍；无 GPU 时自动用 CPU
- 智能结构保留：区分正文/标题/图片/表格/列表/代码块，仅翻译正文和标题
- 任务队列：支持多任务排队、暂停/恢复/取消
- 断点续译：崩溃后可从断点恢复，不重复翻译
- 中文无乱码：嵌入思源黑体，排版紧凑统一
- 纯离线：模型本地运行，不上传任何数据

## 系统要求

- Windows 10/11 (64位)
- 内存：≥ 4GB（推荐 8GB+）
- 磁盘空间：≥ 3GB（含模型下载）
- CPU：任意现代 x86-64 处理器
- 显卡（可选，强烈推荐）：支持 Vulkan 的独立显卡，显存 ≥ 2GB（如 GTX 1060 6GB）
  - 有 GPU：50 页约 **3 分钟**；无 GPU：50 页约 **27 分钟**

## 快速开始

### 1. 安装
运行 `EnTransfer Setup.exe`，按提示安装。

### 2. 获取翻译模型
首次启动后，进入「模型管理」页面，两种方式任选其一：

**方式 A：App 内下载（推荐）**
- 点击 **Qwen3-1.7B（推荐）** 卡片上的「下载」按钮
- 等待下载完成（约 1.2GB，显示百分比、已下载/总大小、速度）
- 下载完成后自动校验，状态变为绿色 **Ready / 已就绪** 即可使用

**方式 B：手动放置模型文件**
- 模型管理页下方有「手动放置模型文件」提示区，显示模型目录的完整路径
- 点击「复制路径」复制目录，或「打开文件夹」直接定位
- 自行下载 `Qwen3-1.7B-Q4_K_M.gguf` 放到该目录（与 App 内下载走同一套识别逻辑，重启后自动识别）

> 下载源默认使用 ModelScope（国内速度快），可在设置中切换。

### 3. 翻译PDF
1. 进入「任务队列」页面
2. 点击「添加PDF」按钮，选择英文PDF文件
3. 任务自动开始翻译，进度条实时显示
4. 翻译完成后，点击「打开文件夹」查看输出的中文PDF

## 界面说明

### 任务队列
- **添加PDF**：选择要翻译的英文PDF
- **全部开始**：恢复所有暂停的任务
- 任务卡片显示：文件名、状态、进度条、当前页/总页数
- 操作按钮：
  - 运行中：暂停 / 取消
  - 已暂停：继续 / 取消
  - 错误：重试 / 取消
  - 已完成：打开文件夹 / 删除

### 模型管理
- 顶部为推荐模型卡片（名称、体积、质量说明、下载按钮）
- **手动放置区**：显示模型目录完整路径，支持「复制路径」「打开文件夹」
- 下载进度：百分比 + 已下载/总大小 + 下载速度
- 已下载模型显示绿色 Ready 状态
- 可设置默认引擎、删除模型释放空间

### 设置
- 默认模型：选择已下载的翻译模型
- **推理性能**：
  - 推理设备：**自动（推荐）** / 仅 CPU / 仅 GPU（Vulkan）
    - 自动：检测到 Vulkan GPU 就用 GPU，否则用 CPU
    - 页面会显示检测到的显卡型号（如「✅ GPU 加速（Vulkan）— NVIDIA GeForce GTX 1060 6GB」）或回退提示
  - 推理线程数：**自动**（推荐）/ 手动
    - 自动：根据 CPU 架构智能选择（混合架构如 12 代酷睿只用 P 核超线程，避开效率核）
    - 手动：拖动滑块在 1 ~ 逻辑核数之间指定
    - 页面会显示 CPU 信息（如「Intel i5-12600KF（6P+4E，16逻辑核），自动选择 12 线程」）
- 输出目录：翻译结果保存位置
- 镜像源：ModelScope / HuggingFace 镜像

## 翻译流程

```
提交任务 → 结构提取 → 翻译 → 重排版 → 导出 → 完成
```

1. **结构提取**：用 pdfjs-dist 提取PDF文本块、坐标、字体信息，分类为标题/正文/代码块/公式/图片
2. **翻译**：仅正文和标题送翻译模型，代码块/公式/图片原样保留
3. **重排版**：清除原英文文本层，嵌入中文字体，自适应字号绘制中文
4. **导出**：保存为中文PDF

## 支持的PDF类型

- ✅ 文字版PDF（非扫描件）
- ✅ 技术书籍、论文、文档
- ✅ 含代码块、表格、图表的PDF
- ❌ 扫描件/图片PDF（需要OCR，本工具不支持）

## 常见问题

**Q: 翻译速度慢？**
A: 有支持 Vulkan 的显卡时，软件会自动用 GPU 加速，50 页约 3 分钟。若页面显示「未检测到 Vulkan GPU」，则回退到 CPU（50 页约 27 分钟）。请在设置「推理设备」确认选的是「自动」或「仅 GPU」；显卡驱动建议保持较新版本。CPU 线程数保持「自动」通常最快——混合架构 CPU 强行加线程反而会争抢内存带宽而变慢。

**Q: 输出PDF有乱码？**
A: 确保使用最新版本，中文字体（思源黑体）已内置。如仍有问题，请检查PDF是否为文字版。

**Q: 可以暂停后关闭程序吗？**
A: 可以。翻译进度自动保存，下次启动后点击「继续」从断点恢复。

**Q: 模型下载失败？**
A: 在设置中切换镜像源。ModelScope 通常在国内速度更快。

**Q: 翻译质量不满意？**
A: Qwen3-1.7B 是 8 模型横评后选出的 en→zh 综合最优小模型（质量 4.9/5）。对于专业术语较多的文档，可在未来版本中支持术语表功能。

## 技术架构

- **框架**：Electron 33 + React 18 + TypeScript
- **PDF处理**：pdfjs-dist（提取）+ pdf-lib（重排版）
- **翻译引擎**：node-llama-cpp + Qwen3-1.7B GGUF Q4_K_M（已关闭 thinking）
- **状态管理**：Zustand
- **样式**：Tailwind CSS
- **打包**：electron-builder (NSIS + zip)
